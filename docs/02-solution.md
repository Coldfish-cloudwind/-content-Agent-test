# 方案与技术取舍

## 决策循环

CLI 验证输入并读取 SQLite 检查点。若任务已完成，则返回已有结果。进行中的任务每轮把输入、当前时钟、已花费费用、素材、报价、脚本和历史工具观察传给模型。模型给出一个 JSON 动作，执行层验证参数和前置条件后调用工具，提交结果与账本，再把新观察传回模型。

api 模式自动重复上述循环。bridge 模式把同一模型请求输出给外部模型，每次收回一个带 revision 的动作。mock 模式采用固定规则，供离线检查执行层。

## 两条实际模型调整路径

- live_budget 中，模型先评估 studio。工具返回 total=12、budget_gap=2、feasible=false，模型改询价 lite，观察 total=8 后制作并保存。
- live_failure 中，studio 报价可行，制作工具返回 injected_unavailable。模型保留检索成功的素材，改询价和制作 lite，最终保存。
- live_stop 中，lite 报价 8、预算 6，模型明确说明缺口为 2 并停止。

这些路径来自本次对话中的 Codex 逐步提交，每个动作在观察上一步真实工具返回后决定。提交的 Trace 保存了简短公开依据。bridge 依赖外部模型控制器，其模型名称属于自报信息。API 模式的真实端到端运行仍待有凭据时验证。

## 工具职责

素材检索采用合成标签匹配。支持 studio 需要视频与图片两类素材，lite 需要至少一条素材。脚本生成工具使用素材描述和固定分镜模板，模型主要负责流程选择与版本调整。

询价返回已花费加未来必要费用、最早完工时间、预算缺口与超时分钟数。制作前须已有对应报价，执行时再次按当前时间和账本计算可行性。已有脚本只能继续相同版本，以免重复花费。保存成功后才能将活动标记为 completed。

## 状态与幂等

SQLite campaigns 表以 campaign_id 为主键。每个检查点 JSON 包含输入、费率版本、revision、素材、报价、脚本、保存方案、账本、失败注入标记、步骤状态和事件历史。

本地工具只修改内存副本，数据库将工具结果、费用、历史和保存方案作为单行原子更新。revision 的比较更新确保并发读到相同旧状态时，仅一个提交成功。冲突的模型动作被丢弃，调用者重新读取再选择。模型调用发生在事务外。

同 ID 不同输入返回冲突。重复成功操作返回已有结果。重启继续 running 的检查点保留当轮计数，incomplete 需要 --resume 开新一轮，累计上限始终保留。历史失败事件保留，聚合步骤状态反映该类工具的最终成功情况。

## 时钟与边界

默认使用真实时钟，并在模型推理后重新检查执行时间。每个成功收费工具还推进模拟制作时间，后续起点为真实时间与上一步模拟完成时间的较晚者。--as-of 用于可复制测试，输入含时区，比较转换为 UTC。

单轮最多 10 步，可设置为 1–32。所有续跑最多 32 步，模型无效动作与错误响应也会计数。API 每次请求超时 30 秒，失败返回明确未完成结果。

## 原生实现取舍

采用 Python 标准库以便评审直接运行，避免框架安装及抽象带来的额外依赖。使用 urllib 接入模型、sqlite3 保存状态、unittest 验证业务，不使用 Agent 框架，因此没有框架版本或额外 Runtime。

现有原子性覆盖本地合成工具。真实远端扣费与数据库事务之间需要业务幂等键、可查询操作 ID 或 outbox 协议，当前实现尚未覆盖该分布式场景。

## 结构化计划和工具审计

planning.py 记录带依赖的计划版本、输入引用、预计及实际费用耗时、触发观察、版本差异、复用结果与快照。contracts.py 发布工具输入输出、依赖、幂等及标准结果结构。工具完成时统一生成 status、cost、duration、output、error、idempotency_key，执行器再绑定实际 step_id、attempt_id 与 run_id。

旧计划和旧尝试保留。重试创建新尝试，原失败结果保持原值。计划状态与工具聚合状态独立，防止以最终成功掩盖历史失败。每次快照与账本、计划和尝试在同一 SQLite 更新中提交。

--catalog 支持外部合成资料及费用耗时表，输入校验后才创建任务。--partial-once 模拟部分素材失败，重试只传入失败 ID，已成功素材复用。四类业务工具均为核心步骤，部分素材满足 lite 依赖时允许明确降级。

素材检索按每任务一次的模拟检索包结算，首次成功项承担包费用，失败项费用为零，包内补取不新增费用。每项获取结果在 item_results 中单独列出。完整对照和边界见 06-requirements-audit.md。
